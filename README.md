# بات مدیریت سانس تلگرام

باتی برای گروه‌های تلگرامی که سانس می‌سازد، لیست اصلی و رزرو را با پیام‌های «هستم / نیستم / شاید باشم» مدیریت می‌کند، یک روز قبل یادآوری می‌فرستد و ۲ ساعت بعد از شروع سانس خودکار آن را می‌بندد.

## راه‌اندازی

```bash
python -m venv .venv
source .venv/bin/activate        # در ویندوز: .venv\Scripts\activate
pip install -r requirements.txt
```

توکن بات (از BotFather@) را در خط اول فایل `token-file.txt` کنار `bot.py` بنویسید. این فایل در `.gitignore` است و هیچ‌وقت commit نمی‌شود.

```bash
python bot.py
```

بات موقع شروع، منوی دستورات («/») را خودش در تلگرام ثبت می‌کند: دستورات عمومی برای همه و دستورات مدیریتی فقط برای ادمین‌های گروه. نیازی به ثبت دستی در BotFather نیست.

داده‌ها در `bot_data.db` (در پوشه‌ای که بات از آن اجرا می‌شود) ذخیره می‌شوند و بعد از ری‌استارت برمی‌گردند.

## تست‌ها

```bash
pip install -r requirements-dev.txt
pytest
```

## ساختار کد

| فایل | مسئولیت |
|---|---|
| `bot.py` | نقطه شروع: خواندن توکن، ثبت handlerها، اجرا |
| `commands.py` | فهرست دستورات؛ هم handlerها و هم منوی «/» تلگرام از همین فهرست ساخته می‌شوند |
| `config.py` | خواندن توکن از فایل و ساعت تهران |
| `handlers.py` | handlerهای تلگرام؛ فقط ورودی را می‌گیرند، قوانین را صدا می‌زنند و جواب می‌دهند |
| `session_model.py` | قوانین سانس (لیست اصلی، رزرو، مهمان، تغییر ظرفیت)؛ بدون تلگرام و دیتابیس |
| `command_input.py` | اعتبارسنجی آرگومان‌های دستورات |
| `time_parser.py` | تبدیل متن فارسی مثل «2شنبه 9:30 صبح» به تاریخ |
| `texts.py` | همه متن‌های فارسی و قالب پیام‌ها |
| `state.py` | وضعیت در حافظه (سانس‌ها و لقب‌ها) و همگام‌سازی با دیتابیس |
| `session_messages.py` | ویرایش، پین و آنپین پیام سانس |
| `jobs.py` | زمان‌بندی یادآوری و پایان خودکار |
| `db.py` | ذخیره‌سازی SQLite |
